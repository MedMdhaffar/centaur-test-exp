# centaur-test-exp
🧠 Project Description

Centaur Test Experiment is a research prototype for automatically testing deep learning libraries using a neurosymbolic approach. The system combines rule generation, constraint validation, and fuzz testing to generate valid and diverse tensor inputs for deep learning APIs.

The goal of this project is to improve the robustness of frameworks such as PyTorch and TensorFlow by detecting crashes, numerical inconsistencies, and incorrect input handling. It explores how large language models and symbolic reasoning techniques can be combined to learn input constraints and guide test generation in complex tensor-based environments.
